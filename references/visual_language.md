# Visual Language Reference (by style)

Nine grounding styles, drawn from analyzed reference clips. Match a new brief to the closest style below, then blend if needed.

## 1. Kinetic-typography product reveal
Gradient background, glowing orbs, kinetic text transitions, floating profile cards, night-sky backdrop. Motion: smooth ease-in/out kinetic type, camera zoom-ins on UI, sliding card transitions, sparkle emission. Use for: brand/identity-led launches.

## 2. Dashboard / growth explainer
Dark green-to-black gradient, single bright accent particle, flowing vector lines, floating dashboard mockups, metric charts. Motion: continuous fluid pan along vector paths, scale-up card reveals, elastic-bounce kinetic type assembly. Use for: analytics, growth, marketing-metric products.

## 3. Dark-mode chatbot / dev-tool promo
Dark neon-green backdrop, glowing headers, floating search bar, code snippet blocks, integration icon grid. Motion: dynamic perspective tilts, rapid spring-eased card reveals, glowing particle trails. Use for: dev tools, AI chat products, technical audiences.

## 4. Isometric enterprise-tech explainer
Deep blue background, isometric glowing 3D cube grids, floating app windows, timeline sliders, cloud visuals. Motion: smooth 3D rotational transitions, grid-tile assembly, camera zoom through digital layers. Use for: enterprise IT, infrastructure, B2B platform products.

## 5. Multi-agent AI demo
Dark minimal backdrop, glowing orange accents, floating browser frames, branching node graphs, kinetic headlines. Motion: precise vector line extensions, node-split animations, linear camera dollies, fast terminal-text typing. Use for: AI agent products, workflow automation.

## 6. Bold promo-burst showcase
Bright white background, bold dynamic typography, floating image carousels, video cutouts, sound-wave visualizer. Motion: fast-paced cuts, pop-in text scaling, sliding grids, quick whip pans. Use for: consumer apps, high-energy feature announcements.

## 7. Mobile app launch (banking/fintech)
Clean light/dark theme mobile mockups, customizable widget grids, floating cards, sleek gradients. Motion: 3D phone rotation/tilt, floating tile reordering, smooth theme transition, gentle spring physics. Use for: mobile-first fintech/consumer apps.

## 8. AI-workflow / node-based platform explainer
Soft green gradient, glowing sphere nodes, flowchart decision trees, toggle switches, security badges. Motion: smooth particle orbit, node branch drawing, slow background camera drift, fluid card stacking. Use for: workflow/automation platforms, enterprise AI.

## 9. Command-palette / minimal feature teaser
Dark grid background, centered search bar, glowing shortcut keys, file grid results, floating 3D logo. Motion: snappy keyboard-trigger animation, modal zoom-in, smooth grid fade-ins, subtle floating isometric rotation. Use for: productivity tools, single-feature teasers.

## Choosing a style
Ask: is the audience developer/technical (styles 3, 5, 9), enterprise/B2B (styles 4, 8), growth/marketing (style 2), consumer (styles 6, 7), or brand-led (style 1)? Most briefs map cleanly to one style; blend two only when the brief explicitly spans categories (e.g. an enterprise AI agent product might blend styles 4 and 5).
