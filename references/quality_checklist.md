# Pre-Delivery Quality Checklist

Run through this before handing prompts back to the user:

- [ ] Every animated element has an explicitly named easing curve (no bare "smoothly")
- [ ] No more than one camera move type per shot (parallax drift excepted)
- [ ] Motion hierarchy is respected — one clear hero element per scene, secondary elements visibly calmer
- [ ] No more than one saturated accent color per scene (unless intentionally in promo-burst style)
- [ ] Multi-element reveals are staggered, not simultaneous
- [ ] Every entrance has a matching settle/overshoot; every exit has a deceleration, not a hard stop
- [ ] Light source direction and color temperature are consistent across the sequence
- [ ] Scene lengths vary — no two consecutive scenes are near-identical duration
- [ ] Text has enough hold time to read comfortably before it starts exiting
- [ ] Negative-rules pass completed (`negative_rules.md`)
- [ ] Prompt follows the structural formula order in `prompt_templates.md`
- [ ] If multi-scene: transitions are motivated (see `transition_library.md`), not arbitrary hard cuts throughout
- [ ] Closing quality/production tag included, but not an over-long adjective dump
